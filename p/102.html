MX Keys SとMiniはサイズがどれくらい違う？

MX Keys Sは430.2 x 131.6 x 20.5mm、810gのフルサイズ機です。MX Keys Miniは、MX KEYS（KX800）の約70%のサイズとされています。Miniの寸法と重量は、販売ページの記載では確認できなかったため、公式ページで確認してください。

比べるときは、机の横幅とマウスを動かす範囲を測っておくと判断しやすくなります。フルサイズ機はマウスの置き場所が狭くなりやすいので、キーボードの右端からマウスまでの余白を見ておきましょう。

テンキーは本当に必要？

MX Keys Sは112キーの日本語レイアウトでテンキー付き、MX Keys Miniはテンキーレスで83キーです。違いが出るのは数字の入力です。表計算や経理作業などで数字を打つ頻度を思い出してみてください。

数字を打つ機会が多いならMX Keys Sが候補になります。数字入力が少なく、机の広さを優先したい場合はMX Keys Miniが合います。Miniでテンキーが必要になったときの対処は、販売ページで確認してください。

接続方式と対応OSの注意点は？

MX Keys SはBluetoothとUSBレシーバー（Logi Bolt）に対応しています。MX Keys MiniもBluetoothとLogi Boltに対応していますが、Unifyingには非対応と明記されています。

手持ちのUnifying受信機を使い回すつもりの人は注意が必要です。Logi Bolt対応の受信機を使うかどうかを先に決めておきましょう。MX Keys MiniはWindows・Macに対応しています。MX Keys SのOS対応は、販売ページで確認してください。
