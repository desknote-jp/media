MX Keys SとMiniの幅と重さはどれくらい違う？

サイズ差は机の使い方に直結します。MX Keys Sは430.2×131.6×20.5mmで810g、MX Keys Mini（KX700GRdr）は販売ページの掲載値で296×132×21mm、公式プレスリリースの案内値で506gです。

購入前に、キーボードを置く場所の横幅と、右側にあるマウスの動かす範囲を測ってみてください。テンキー付きのSを置くと、マウスが右に寄ることがあります。

なおMiniの寸法と重さは出典が別々です。細かい数値は購入前に販売ページで見比べてください。

テンキーなしでも困らない？

MX Keys Sはテンキー付きで、112キーの日本語レイアウトです。MX Keys Mini（KX700GRdr）はテンキーレスで、フルサイズ版からテンキーを除いた約70%のサイズとされています。

まず、普段の作業で数字をどれだけ打つかを振り返りましょう。表計算や経理のように数字入力が多いならS、机の幅を優先するならMiniが候補になります。

テンキーが必要でもMiniを選びたい場合、別売りのテンキーが使えるかどうかは、今回確認できた販売ページの記載にはありません。販売ページで確認してください。

接続方式と台数は同じ？

MX Keys SもMX Keys Mini（KX700GRdr）も、BluetoothとLogi Boltに対応しています。パソコン側にBluetoothがあるか、Logi Bolt対応の受信機を使うかを先に確認しましょう。

Miniは旧規格のUnifyingに非対応と明記されています。手持ちの受信機がUnifying用の場合は、そのままでは使えない可能性があります。

MiniはBluetoothで最大3台に接続でき、Easy-Switchで切り替えられます。Sの接続台数は、販売ページの記載では確認できなかったため、購入前に確認してください。

MX Keys Sは810g、MX Keys Miniは公式プレスリリースの案内値で506gです。Miniの寸法は販売ページ掲載値で296×132×21mmです。
